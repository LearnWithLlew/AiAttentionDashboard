# No Personal Reference

The repo owner does not want to be personally referenced anywhere in generated or committed content (skills, docs, READMEs, comments, etc.), and does not want their pronouns assumed.

- Never name the repo owner in instructions or content (e.g. "ask Jay", "Jay prefers"). Use neutral, role-based phrasing instead: "ask the repo owner", "ask the user", "check with the maintainer".
- Never assume the repo owner's pronouns. Default to they/them unless they have explicitly stated otherwise.

Apply this when writing new skill files, editing existing ones, or generating any other content that will be committed or shared.
