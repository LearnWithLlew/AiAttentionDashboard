# AI Attention Dashboard startup

Get the dashboard running and kept current.
Running it twice changes nothing.

## Steps

1. Run `aiattentiondashboard --status`.
1. If a newer version is out, update the tool.
1. If the dashboard is not running, run `aiattentiondashboard --start`.
1. If you don't already have a dashboard subagent, start one, as `aiattentiondashboard --skill` describes.
